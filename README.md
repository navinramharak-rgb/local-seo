# Local SEO

Get found by people searching in your own city.

For a plumber, a clinic, a law firm, a car wash or a restaurant, the Google Business Profile does more work than the website, and almost nobody ever finishes setting it up. This skill starts there, then works outward.

## Install

```
/plugin marketplace add navinramharak-rgb/local-seo
```

Then: `I'm not showing up on Google for [your service] in [your city]`

## The order it works in

1. **Google Business Profile.** Free, about an hour, usually where the movement comes from. Category, service area, services, photos, Q&A, posts.
2. **Reviews.** The strongest local lever that is also a sales asset. The ask, the timing, the replies, the cadence.
3. **Service and area pages.** One page per thing you want to rank for.
4. **Citations.** The dozen that matter, including the Canadian ones most guides skip.
5. **Local schema.** Copy-paste ready, filled in with your real details.

Most people do this list backwards, starting with the website and never touching the profile.

## What it won't do

It will not build you a review gating funnel, offer incentives for reviews, or write fake ones. Those break Google's policies and can cost you the listing. It says so and gives you the version that works instead.

It also never invents a ranking, a search volume or a competitor's review count. It looks it up or tells you it couldn't check.

## Chains with

- **[website-audit](https://github.com/navinramharak-rgb/website-audit)** — run that first if you have a website. This skill assumes the site isn't fundamentally broken.
- **[50k-website-builder](https://github.com/navinramharak-rgb/50k-website-builder)** — when the audit says rebuild, build it with the service and area page structure already in place.

For technical SEO beyond local (hreflang, crawl budget, international, programmatic pages), use [Corey Haines' marketing skills](https://github.com/coreyhaines31/marketingskills). That library is excellent and goes far deeper on that axis. This one deliberately covers what it doesn't: the local half.
